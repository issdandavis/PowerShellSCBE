# SCBE tools for PowerShell

This directory nests the **SCBE CLI tool surface** inside the PowerShell fork and
exposes it to AI assistants programmatically over **MCP** (Model Context Protocol).

It is the "programmatic access for AI" layer: every `scbe` command (chemistry,
the entropy sieve, encoding/number-finding, fleet routing, the scheduler, the
governance score, …) becomes a tool an AI can **discover and actually run**.

## Contents

| File | What it is |
|------|------------|
| `manifest.json` | The tool catalog — every SCBE command with its args/schema (generated by `scbe manifest`). |
| `scbe_cli_server.py` | A zero-dependency MCP stdio server. Lists the catalog, and on a call runs the real `scbe` CLI. |
| `SCBE.psm1` | PowerShell module: `Get-ScbeManifest`, `Invoke-ScbeTool`, `Start-ScbeMcp`, `Test-ScbeMcp`. |

## Point it at your SCBE checkout

Discovery works offline from `manifest.json`. To **execute** tools, tell it where
`scbe.py` lives (once per session):

```powershell
$env:SCBE_CLI  = 'C:\path\to\scbe-aethermoore\scbe.py'   # path to scbe.py
# ...or just the repo root:
$env:SCBE_REPO = 'C:\path\to\scbe-aethermoore'
```

## Use it from PowerShell

```powershell
Import-Module ./scbe/SCBE.psm1

Get-ScbeManifest -Names                                  # list every tool path
Invoke-ScbeTool -Name score -ArgumentList 'find me a prime'
Invoke-ScbeTool -Name 'chem atomize' -ArgumentList 'water'
Test-ScbeMcp                                             # MCP self-test
```

## Use it from an AI client (MCP)

Register the server with any MCP client (Claude Desktop, gemini-cli, etc.):

```json
{
  "mcpServers": {
    "scbe": {
      "command": "python",
      "args": ["C:/path/to/PowerShellSCBE/scbe/scbe_cli_server.py"],
      "env": { "SCBE_CLI": "C:/path/to/scbe-aethermoore/scbe.py" }
    }
  }
}
```

The AI then sees every SCBE tool (`scbe_score`, `scbe_chem_atomize`, `scbe_encode`,
`scbe_route`, `scbe_schedule`, …) and invokes the real engine — no fakes.

## Refresh the catalog

When the SCBE CLI gains or changes commands, regenerate the manifest:

```powershell
python C:\path\to\scbe-aethermoore\scbe.py manifest > scbe\manifest.json
```
